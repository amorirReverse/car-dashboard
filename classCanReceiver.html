Detailed Description

Classe responsable de l'écoute du bus CAN et de l'exposition de la télémétrie à QML.

Classe de base de Qt. Nécessaire pour utiliser les signaux et slots. Permet de gérer le multithreading avec Qt. Fournit des variables thread-safe natives C++ pour éviter les accès concurrents non synchronisés.

Cette classe hérite de QObject et utilise un thread secondaire pour effectuer des lectures bloquantes sur la socket Linux CAN sans figer l'interface utilisateur.
